# uniloaders.github.io

The website of [uniloader](https://github.com/uniloaders/uniloader): installation on the main
page, documentation under [`docs/`](docs/). It is plain markdown rendered by GitHub Pages'
built-in Jekyll; `_layouts/default.html` and `assets/style.css` are the whole theme.

To preview locally:

```bash
jekyll serve
```

The docs describe the code on uniloader's `main` branch. When a change there alters
something a page states (a command, a setting, a host function, a file path), update the page
in the same breath.
